# 🌡️ Desktop Weather Widget

A lightweight Python desktop widget that sits on your desktop background showing:

- 🕐 Live time (updates every second)
- 📅 Current date
- 🌡️ Real-time temperature (auto-updates every 5 mins)
- 📍 Your city (auto-detected by IP)

## 📸 Preview
Widget sits in the bottom-right corner of your desktop — behind all apps!

## ⚙️ Requirements
- Python 3.x
- requests library

## 🚀 How to Run

### Step 1 — Install dependency
pip install requests

### Step 2 — Run the widget
python weather_widget.py

## ✨ Features
- Stays behind all apps (true desktop widget)
- Drag to reposition anywhere
- Right-click to close
- Smooth clock & temperature updates
- No API key needed — 100% free!

## 🌍 How it works
- Location detected automatically via IP
- Weather data from Open-Meteo (free, no signup)
